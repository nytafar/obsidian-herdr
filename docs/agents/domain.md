# Domain docs

The docs root for this repo is `~/hvelv/repos/obsidian-herdr/` in the vault.
It holds `CONTEXT.md` (the glossary, created when the first term is settled),
`adr/` (hard decisions, numbered) and `findings/` (one file per topic of
discussion or verified fact). The repo itself keeps only instructions and
user-facing docs; `docs/architecture.md` is the verified herdr contract.
